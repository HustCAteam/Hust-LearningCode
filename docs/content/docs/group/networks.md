## 把 HTTP 请求发到本机

按[工具实作：本地 HTTP](../guide/tools.md#本地-http-请求)建立 web/index.txt，运行 Python HTTP 服务，再用 curl 查看 200、404 和 Content-Length。将文件正文改为 hello group 后重新请求，响应正文应同步改变。结合本页书籍的应用层章节，逐项解释请求方法、路径、状态码和响应头。
