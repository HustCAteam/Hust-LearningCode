## 怎么开始读

语言入门可读《C++ Primer Plus》，随后用五份调试原稿练习定位错误。熟悉类、对象和资源管理后，再阅读 Effective C++ 系列。EasyX 扫雷与贪吃蛇适合结合窗口、输入和游戏状态继续练习。
