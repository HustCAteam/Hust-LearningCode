群里的算法书架包含图解入门、系统教材、算法分析和竞赛讲义。不同书的叙述方式与练习侧重点各有特色，可以按自己正在解决的问题选择。

## 怎么开始读

想先建立直觉，可以翻阅《算法图解》或《啊哈算法》；需要系统学习时，可从《算法导论》或《算法：C 语言实现》进入。竞赛材料集中在《算法竞赛入门经典》《算法笔记》和《深入浅出程序设计竞赛》。
