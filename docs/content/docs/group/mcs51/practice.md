## 按课件完成定时器实验

阅读 01 结构、03 实验板与 GPIO，再打开 08 C51 定时器课件。使用 Keil µVision 的 8051 工程，器件选择 AT89C52；新建 main.c，在定时器 0 中断函数中翻转 P1.0。12 MHz 晶振、传统 12T 内核的 1 ms 重装值为 65536−1000=64536，即 TH0=0xFC、TL0=0x18。设置 TMOD=0x01、ET0=1、EA=1、TR0=1。进入 Simulator，在 Logic Analyzer 添加 P1.0，预期相邻翻转间隔约 1 ms，完整周期约 2 ms。若引脚恒定，检查中断向量 interrupt 1、总中断 EA 与运行位 TR0；若周期偏差 12 倍，检查目标芯片的 1T/12T 模式。硬件接线与外设地址使用群内对应实验板课件。
