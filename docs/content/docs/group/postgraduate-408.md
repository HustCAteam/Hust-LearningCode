## 用一道题串起四门基础课

先独立完成本页 2024 年 408 回忆版中的一道进程同步题，明确每个信号量的初值、P/V 操作位置和临界区。再执行[操作系统安全序列练习](operating-systems.md)，比较 available=1 与 0 两种输入。网络题配合[子网计算练习](network-certification.md)完成 192.168.10.37/27 的网络地址 192.168.10.32、广播地址 192.168.10.63 和可用主机数 30。
