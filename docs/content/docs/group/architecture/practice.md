## 从群内论文还原一次乘加的数据流

先打开主题目录中的 CIMR-V 论文，定位 SRAM 存内计算的结构图，标出输入向量、权重、累加器三条路径。取输入 [1,2]、权重 [3,4]，手算点积为 11；沿论文的数据通路逐级填入乘积 3、8 与累加结果 11。继续阅读处理器功耗估算论文的计数器定义，选取其中一个计数器解释采样窗口与单位。需要先补指令基础时，执行[组成原理的 gcc/objdump 实验](../computer-organization/practice.md)。
