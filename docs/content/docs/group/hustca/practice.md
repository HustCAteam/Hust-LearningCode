## 从一次可演示的分享开始

阅读主题目录中的协会介绍后，可用[本地 HTTP 实验](../../guide/tools.md#本地-http-请求)准备一次五分钟演示：第一终端启动端口 8000，第二终端请求 /index.txt 得到 200，再请求 /missing 得到 404。演示时逐行解释状态码、Content-Type 与正文。把你实现的例子、运行环境和署名通过[分享资料](../../guide/contributing.md)入口提交。
