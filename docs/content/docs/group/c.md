从循环、数组和指针开始，读懂一个 C 程序怎样使用内存。这一栏汇集群友分享的入门教材、课程试题、循环实验与小程序，也收录两份 C 语言标准。

## 怎么开始读

初学时可从《啊哈 C 语言》或《C Primer Plus》选一本连续阅读，配合循环实验动手。学过指针之后，再读《C 和指针》与《C 专家编程》。复习资料按试题、答案和笔记分别列出，便于先做题再对照。
