## 做一个带测试的课程设计切片

先打开本页《软件课程设计选题与文档要求》，选择其中一个题目。以学生成绩管理为例，先按[工具实作：SQLite 查询计划](../guide/tools.md#sqlite-查询计划)建立 students 表，完成按专业查询、成绩修改和回滚三个操作；再用[软件工程练习](software-engineering.md)的 unittest 形式为 99/100 两个边界写测试。界面接入前，SQL 查询应返回 A 的分数 85，回滚后仍为 85。
