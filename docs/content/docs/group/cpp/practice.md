## 从群友程序开始调试

群友的交换排序、数组插入、数组删除、阶乘与幂函数、猜数游戏源程序可按[完整调试练习](../../guide/cpp-debugging.md)逐个编译，使用文中的固定输入和结果检查每一处修改。数组插入的目标输出为 `1 99 2 3 999 4 5 6 7 8 9 10`，猜数输入为 `20 60 42`。EasyX 扫雷与贪吃蛇程序使用 Windows 和 EasyX；下载多文件项目后保留其图片目录，在 Visual Studio 中配置 EasyX，再按项目内的运行说明设置工作目录。
