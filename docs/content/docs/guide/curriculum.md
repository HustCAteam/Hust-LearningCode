按入学年级和专业打开学院的培养方案，查找课程名称、学分与先修关系，再从[学码群资料](../group/index.md)选择相应教材与练习。

- [2026 年培养方案](https://cs.hust.edu.cn/info/1076/6346.htm)
- [2025 年培养方案](https://cs.hust.edu.cn/info/1076/5608.htm)
- [2024 年培养方案](https://cs.hust.edu.cn/info/1076/4512.htm)
- [2023 年培养方案](https://cs.hust.edu.cn/info/1076/3376.htm)

例如准备学习操作系统时，在自己的方案中找到该课程的学期和先修要求，再打开[操作系统群专题](../group/operating-systems.md)，先做银行家算法例题。
