[学码群资料](../group/index.md)按主题展示群友上传的教材、课件、试题与源程序。[书籍](../books/index.md)提供教材的直接下载入口，作者与群文件上传者列在每份资料旁。

## 第一次编程

打开 [C 语言群资料](../group/c.md)，选择《实验三：循环程序设计》，先完成页面中的 sum.c，编译后应输出 15。接着完成[数组越界练习](tools.md#c-数组越界与-addresssanitizer)，对照 ASan 指出的 bounds.c 第 5 行，把 <= 修正为 <，得到输出 60。

## 正在复习 C++

下载 [C++ 群资料](../group/cpp.md)中的交换排序源程序。按[调试手记](cpp-debugging.md)调整提前退出的位置，原稿数组排序后应输出 13 34 42 43 64 76 94 316 431 435 1513 431366。

## 正在学网络与系统

执行[本地 HTTP 与 SQLite](tools.md)，分别观察 200/404 响应和 SCAN/SEARCH 查询计划。再去相应群专题读教材中的应用层、索引和事务章节。
