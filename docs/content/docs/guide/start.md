学码群的资料从一次次具体的分享积累而来。你可以带着正在学的课程来找材料，也可以先翻翻书架，看哪一本让你想继续读。

## 找一门课

进入[资料目录](../group/index.md)，选择主题。每页先介绍收录范围和阅读顺序，再分别列出书籍、讲义、笔记、试题与代码。点击资料名称，会进入它自己的介绍页。

复习 C 语言与数据结构时，试卷和答案分别列出。可以先下载试卷，完成后再打开答案。单片机讲义则按 01—10 的原系列顺序排列，方便循序阅读。

## 选一本书

[共同书架](../books/index.md)按主题摆放群友分享的读物。主题书架展示每本书的介绍、作者与上传者，具体版本和文件入口在书籍详情页中。

例如，[C 语言书架](../books/c.md)包含入门教材、指针专题与语言标准；[系统书架](../books/computer-systems.md)连接程序执行与 Linux 使用；[算法书架](../books/algorithms.md)涵盖图解入门、算法分析与竞赛。

## 从程序里学

[C++ 群程序](../group/cpp.md)保留了数组、排序和猜数游戏的调试原稿。[调试手记](cpp-debugging.md)逐个解释问题，并给出可以尝试的输入与结果。

[动手工具](tools.md)提供 GCC、AddressSanitizer、GDB、本地 HTTP 请求和 SQLite 查询计划的练习。可以在阅读教材的同时，用这些工具观察程序的实际行为。

## 找讲义、试题或代码

已确定想要哪种资料时，直接使用[资料形式索引](../formats/index.md)。页面右上角的搜索也支持书名、主题与分享者；使用 Ctrl / ⌘ + K 可以快速打开。

## 留下一点自己的收获

如果材料帮到了你，欢迎补一段读后体会或课堂使用经验。也欢迎分享自己的笔记、实验和项目。我们会把你的署名与贡献一起保留在[资料库](contributing.md)中。
