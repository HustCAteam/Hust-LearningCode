# 数据可视化技术

数据表达、图表设计与交互。

## 学习起点

- 建议基础：Python 与基本统计。
- 动手练习：为同一组数据选择两种图形并解释各自的信息重点。
- 华科资料目录：IIIB 数据可视化技术。

这里的学习建议由学码群整理，可结合本学期的课堂安排选择内容。
