# 计算机图形学

几何变换、光栅化与渲染。

## 学习起点

- 建议基础：线性代数与 C\+\+。
- 动手练习：从三角形开始完成一次模型、视图和投影变换。
- 华科资料目录：IIB 计算机图形学。

这里的学习建议由学码群整理，可结合本学期的课堂安排选择内容。
