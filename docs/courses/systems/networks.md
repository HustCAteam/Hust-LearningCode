# 计算机网络与通信

分层、路由、可靠传输与拥塞控制。

## 学习起点

- 建议基础：基本编程与操作系统基础。
- 动手练习：解析一次 traceroute 的 ICMP 回包，并画出封装层次。
- 华科资料目录：IIIA 计算机网络与通信。

这里的学习建议由学码群整理，可结合本学期的课堂安排选择内容。
