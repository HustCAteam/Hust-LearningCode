# 编译原理

词法、语法、语义、中间表示与代码生成。

## 学习起点

- 建议基础：数据结构、汇编与形式语言。
- 动手练习：从表达式解析开始，逐步生成能运行的目标程序。
- 华科资料目录：IIIB 编译原理。

这里的学习建议由学码群整理，可结合本学期的课堂安排选择内容。
