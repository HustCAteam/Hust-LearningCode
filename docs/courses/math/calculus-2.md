# 微积分（二）

多元函数、重积分与级数。

## 学习起点

- 建议基础：一元微积分。
- 动手练习：为一个二维积分画出区域并比较两种积分次序。
- 华科资料目录：IB 微积分（二）。

这里的学习建议由学码群整理，可结合本学期的课堂安排选择内容。
