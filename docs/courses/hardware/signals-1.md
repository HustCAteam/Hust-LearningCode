# 信号与线性系统

信号、系统、卷积与频域分析。

## 学习起点

- 建议基础：微积分与复数。
- 动手练习：对两个简单离散信号实现卷积并画出结果。
- 华科资料目录：IIA 信号与线性系统。

这里的学习建议由学码群整理，可结合本学期的课堂安排选择内容。
