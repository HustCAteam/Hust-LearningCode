# 数字逻辑

组合逻辑、时序逻辑与状态机。

## 学习起点

- 建议基础：二进制表示。
- 动手练习：设计一个交通灯状态机，并写出状态转移表。
- 华科资料目录：IIA 数字逻辑。

这里的学习建议由学码群整理，可结合本学期的课堂安排选择内容。
