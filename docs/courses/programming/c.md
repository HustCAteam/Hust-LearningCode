# C语言程序设计

表达式、控制流、数组、指针与内存。

## 学习起点

- 建议基础：高中数学。
- 动手练习：写一个读取文本并统计词频的命令行程序。
- 华科资料目录：IA C语言程序设计。

这里的学习建议由学码群整理，可结合本学期的课堂安排选择内容。
