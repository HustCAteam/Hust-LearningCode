# 算法设计与分析

分治、贪心、动态规划与图算法。

## 学习起点

- 建议基础：数据结构与离散数学。
- 动手练习：给同一问题写暴力和优化版本，用随机小数据交叉检验。
- 华科资料目录：IIA 算法设计与分析。

这里的学习建议由学码群整理，可结合本学期的课堂安排选择内容。
