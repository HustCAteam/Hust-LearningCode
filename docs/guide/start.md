# 使用这本手册

可以把这里当成放在书桌旁的资料索引。正在学哪一门课，就从那门课进入，找到课堂材料，再选一份适合自己的补充内容。

## 找到一门课

首页支持中文课名、英文标识和主题词检索。比如输入“网络”“操作系统”“cpp”，可以缩小目录范围。侧栏按主题分类，[完整课程目录](../courses/index.md)适合逐项浏览。

课程页提供学习起点、动手练习、华科原始资料和相关自学入口；已归档的群资料会列在对应页面。华科资料保留上游目录名称，选择时可以对照自己的年级、专业和任课教师。群内的单片机、工具和协会分享也有独立专题，适合从具体问题进入。

## 读一份资料

先翻目录，找到目前遇到的问题。对讲义里的定义写一个自己的例子，对算法画一遍过程，对实验跑一个最小输入。阅读过程中把新问题记在同一个地方，方便下一次接着看。

文件链接会带到原始仓库；Markdown 笔记可以在线阅读，PDF 通常可以在浏览器内打开。容量较大的材料适合按章节取用。

华科文件入口固定到整理时的版本，课程页的上游目录入口可继续查看后续更新。先看文件名中的年份、章节和适用班级，再对照本学期课程要求；历史试题适合练习概念、题型和解题过程。自学课程按同一学期的讲义、实验框架和说明配套使用，环境记录也一同保存。

## 安排一次学习

先决定今天要完成的具体动作：解释一个概念、写出一个函数、跑通一个实验。结束时留下三样东西：完成的结果、遇到的问题、下一步从哪里开始。

希望沿着一个方向系统学习时，可以继续阅读[学习路线](roadmap.md)。

## 分享你的收获

发一个资料链接、补一句用途说明、写一页实验记录都很好。你可以通过 Issue 提交，也可以直接修改文件发起 Pull Request。[补充资料](contributing.md)介绍了文件放置和署名方式。
