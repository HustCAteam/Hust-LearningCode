## 目录快照

- Hust-opensource-Xuejie：`4a710e81d217c0b30e6968224bb953d11b0aca36`。
- CS 自学指南：`2c591834a1e4101e2e7579dc7f49bdeb4a6153a2`。

具体华科文件链接固定到本次核对的版本，课程页同时提供上游最新目录。自学入口连接到 CS 自学指南在线页面。目录元数据位于 `data/`，学习起点、小练习和路线文字由本仓库整理。

目录覆盖华科资料源中的全部 74 个顶层课程与专题目录，包含通识、历史课程、不同专业与研究生材料。精选文件入口记录上游路径、字节数与 Git 对象摘要，项目入口保留原始仓库地址。这里按主题连接学习材料；年级、专业与必选修安排可从[培养方案](curriculum.md)查找。

CS 自学指南的 135 个导航入口包括课程、工具、书目与路线，路径对应上述版本的 `mkdocs.yml` 和文档树。少数显示标题按课程原始编号订正，链接继续保留指南的文档路径。例如概率进阶使用的 `CS126.md` 对应 Berkeley EE126，信号与系统对应 MIT RES.6-007。课程搭配表示可以互相补充的知识主题，学习时按各自的先修要求选择章节。

## 按版本使用资料

点击固定版本的具体文件，可查看整理时的内容；点击课程页的上游目录，可继续浏览最新文件与更多章节。资料中的年份、班级和环境说明帮助选择配套版本。较大的压缩讲义在原始仓库按需获取，本仓库保留索引。

部分目录通过子项目提供代码，按上游 `.gitmodules` 和 `repo.md` 提取原始项目入口。`IIIB 嵌入式系统` 在快照中保留了 `embedded-system` 子模块对象，配套地址未列入 `.gitmodules`；该课程页保留上游目录入口，相关环境指南可从 `IIIA 嵌入式系统` 查找。

公开课程站点的资料开放方式各异。比如 EE126 的 2020 年课程站点当前跳转到校内登录页，指南同时提供 Jean Walrand 的[配套公开教材与 Notebook](https://jeanwalrand.github.io/PeecsJB/intro.html)，可从中继续学习概率与算法的联系。

## 资料署名

本仓库通过链接保留公共材料的原始发布位置。群内文件接入时分别登记作者、上传者和整理者；文档中的原始署名与附带许可一同保留。需要调整来源、版本或署名时，可以在[资料补充表](https://github.com/HustCAteam/Hust-LearningCode/issues/new?template=resource.yml)中说明。
