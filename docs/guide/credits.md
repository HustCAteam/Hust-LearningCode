# 贡献与致谢

这份手册从群友们长期的分享中生长。有人写下课堂笔记，有人整理实验环境，有人把自己绕过的弯路讲清楚，也有人发现旧链接失效后补上新的入口。谢谢你们愿意花时间，把这些经验交到下一位同学手里。

## 群内资料贡献者

每份已接入的资料在[群资料目录](../group/index.md)和相关课程页中展示上传者、已知原作者与后续贡献者。谢谢最初创作内容的人、把资料带到群里的朋友，以及继续整理和纠错的同学。希望补充或调整署名时，可以在[Issue](https://github.com/HustCAteam/Hust-LearningCode/issues/new)中留下资料链接、角色和希望展示的名字，也可以直接提交修改。

## 课程资料与自学社区

- [Sukuna 与 Hust-opensource-Xuejie 的贡献者](https://github.com/SukunaShinmyoumaru-hust/Hust-opensource-Xuejie/graphs/contributors)：持续整理华科课程讲义、实验和学习资料，为本仓库提供具体课程入口。
- [PKUFlyingPig 与 CS 自学指南的贡献者](https://github.com/PKUFlyingPig/cs-self-learning/graphs/contributors)：整理公开课程、教材和工具经验，让更多同学能够沿着自己的兴趣继续学习。
- 各课程的教师、助教、教材作者与开源项目维护者：把课程、文档和实验带到公开网络上。
- 华科学码群的每一位分享者与维护者：让资料在交流中获得新的解释、补充和连接。

## 参与这份手册

[GitHub 贡献记录](https://github.com/HustCAteam/Hust-LearningCode/graphs/contributors)记录仓库中的修改。[补充资料](contributing.md)介绍了通过文件、链接或文字参与的方式。
